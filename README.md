# Laos Trip Expense Tracker

A simple, mobile-friendly web application to track and split expenses during your trip to Laos.

## Features
- **Real-time Sync:** Powered by Firebase Firestore. Everyone sees updates instantly.
- **Dual Currency:** Input expenses in Thai Baht (THB) or Lao Kip (LAK).
- **Exchange Rate:** Set your own exchange rate (e.g., 1 THB = 600 LAK).
- **Real-time Splitting:** Automatically calculates total spent and per-person share.
- **Settlements:** Shows exactly who needs to collect money and who owes.
- **Persistent:** Saves all data to your browser's local storage.

## How to Run
1. Open your terminal in this folder.
2. Run `npm run dev`.
3. Open the provided link (usually `http://localhost:5173`) in your browser.

## Tech Stack
- React
- TypeScript
- Vite
